# Sales-Dashboard-Project
This project is a Sales Dashboard built for visualizing key sales metrics using interactive charts and visual elements. It provides insights into profit, quantity sold, and transaction details categorized by various dimensions such as customer, product sub-category, and payment mode.

#Features
Quarter Selection: Interactive filters to view data by quarters (Qtr 1 to Qtr 4).
KPI Indicators:
Sum of Quantity: 5,615 units
Sum of Profit: 37K
Sum of Amount: 438K
Top Sub-Categories by Profit:
Printers: 8.6K
Bookcases: 6.5K
Saree: 4.1K
Accessories: 3.4K
Payment Mode Analysis: Donut chart showing distribution of sales quantity across various payment modes.
Profit Trend by Month: Line chart showing monthly profit fluctuation with peaks in January and December.
Customer Spending Overview: Bar chart displaying top customers by purchase amount.
Category Performance: Donut chart visualizing quantity and amount by product categories.

Data Visualization Charts:
Bar Charts
Donut Charts
Line Charts
Gradient UI Design with vibrant themes for better readability

📌 Use Cases
Performance tracking across months and categories
Customer insights for targeting high-value buyers
Inventory planning using quantity sold by sub-categories
Strategic decisions using profit trends
